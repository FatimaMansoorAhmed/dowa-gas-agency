One technical note worth knowing before you review: Urdu script itself always reads right-to-left, even though the app's overall layout is staying left-to-right as agreed. In the table below, the Urdu column is set dir="rtl" on its own — that's exactly how it will behave inside the app too: an English-LTR page with correctly right-to-left Urdu text sitting inside individual labels and fields. This is normal and is not the "RTL layout mirroring" that was ruled out.
